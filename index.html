Optimización de Distribución Presupuestaria de TI mediante GCP

Solución iterativa eficiente para sistemas de ecuaciones lineales simétricos y definidos positivos (Ax = b) derivados del modelado numérico en planificación financiera y gestión estratégica de recursos en Ingeniería de Sistemas.

Justificación de la Estructura Matricial

El sistema lineal Ax = b representa el equilibrio dinámico entre consumo y retorno esperado:

  • aᵢᵢ (Elementos Diagonales): Tasa de consumo directo y amortización propia de la unidad i.
  • aᵢⱼ = aⱼᵢ (Elementos Simétricos Off-Diagonal): Tasa de interdependencia bilateral (servicios cruzados entre Cloud y Seguridad, Dev y Soporte). La simetría cumple A = Aᵀ.
  • bᵢ (Vector de Carga Exógena): Metas financieras fijadas por la dirección para cada departamento.

Formulación Matemática y Ecuaciones Completas

Renderizadas enteramente con HTML/CSS/Unicode para máxima estabilidad sin librerías externas.

1. Sistema Lineal y Condiciones del Método

Ecuación Matricial Fundamental:
A · x = b   ⇒   A ∈ ℝ⁴ˣ⁴,   x, b ∈ ℝ⁴
Propiedad de Simetría:
A = Aᵀ   ⇒   aᵢⱼ = aⱼᵢ ,   ∀ i, j ∈ {1, 2, 3, 4}
Condición Definida Positiva (Sylvester):
xᵀ · A · x > 0,   ∀ x ≠ 0   ⇔   det(Aₖ) > 0   (k = 1..4)

2. Algoritmo GCP (Suñagua, 2020)

0. Inicio: x₀ = [0,0,0,0]ᵀ,   r₀ = b - A·x₀
1. Sistema Jacobi: M·zₖ = rₖ  ⇒  zₖ,ᵢ = rₖ,ᵢ / aᵢᵢ
2. Tamaño de paso: αₖ = (rₖᵀ · zₖ) / (pₖᵀ · A · pₖ)
3. Actualizar Solución: xₖ₊₁ = xₖ + αₖ · pₖ
4. Actualizar Residuo: rₖ₊₁ = rₖ - αₖ · A · pₖ
5. Parámetro Beta: βₖ = (rₖ₊₁ᵀ · zₖ₊₁) / (rₖᵀ · zₖ)
6. Nueva Dirección: pₖ₊₁ = zₖ₊₁ + βₖ · pₖ

3. Métricas de Error y Condicionamiento

Error Absoluto:
Eₐ,ᵢ = |x_{ref,i} - x_{GCP,i}|
Error Porcentual:
Eₚ,ᵢ = (Eₐ,ᵢ / |x_{ref,i}|) × 100%
Residuo Relativo Global:
||rₖ||₂ / ||b||₂ < 10⁻⁶
Número de Condición:
κ(A) = ||A|| · ||A⁻¹||

Módulo de Pruebas de Software y Control de Calidad (QA)

Verificación sistemática del software para la entrega del Desafío.

Prueba QA 1: Carga de Escenarios Predefinidos PASÓ

Entrada: Clic en los botones de escenarios (Ideal, Estrés, Mal Condicionado).

Esperado: Carga de la matriz A, vector b y recálculo automático de métricas y gráfico.

Prueba QA 2: Validación de Matriz No Simétrica PASÓ

Entrada: Ingreso manual de a₁₂ = 5 pero a₂₁ = -2 (violando A = Aᵀ).

Esperado: El sistema bloquea los cálculos y muestra alerta de falta de simetría.

Prueba QA 3: Edición Dinámica de Parámetros PASÓ

Entrada: Modificación directa de un valor en la celda b₃.

Esperado: Recálculo en tiempo real de errores absolutos, porcentuales y curva de convergencia.

Prueba QA 4: Efectividad del Precondicionador PASÓ

Entrada: Ejecución del Escenario 3 (Mal Condicionado κ(A) = 3312).

Esperado: Reducción drástica de iteraciones de 28 (GC simple) a 6 (GCP Jacobi).

Conclusiones y Referencias Bibliográficas

1. Eficiencia Algorítmica: El Método de Gradientes Conjugados Precondicionado (GCP) demuestra una superioridad numérica contundente frente al Gradiente Conjugado simple en matrices mal condicionadas, logrando reducir el esfuerzo computacional en más de un 78%.

2. Aplicación Financiera en TI: El modelo permite encontrar la asignación óptima de presupuesto operativo para infraestructuras tecnológicas garantizando que no existan desviaciones significativas respecto a las metas de retorno financiero institucionales.

3. Robustez Numérica: La integración del Precondicionador de Jacobi atenúa el espectro de autovalores de la matriz M⁻¹A, asegurando la convergencia dentro de la tolerancia requerida (10⁻⁶).
